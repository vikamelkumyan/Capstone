# Legacy Single-Intersection SUMO Files

These files belong to the earlier single-intersection Vagharshyan experiment:

- `komitas-vagharshyan.net.xml`
- `komitas-vagharshyan.osm`
- `komitas-vagharshyan.sumocfg`

They are preserved for project history and comparison only. The active capstone implementation uses the multi-intersection Komitas corridor files in the parent `sumo_data/` directory:

- `komitas.net.xml`
- `komitas.osm`
- `komitas.sumocfg`
- `routes.rou.xml`
